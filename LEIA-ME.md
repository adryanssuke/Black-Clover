# Black Clover: Grimoire Chronicles (versão inicial)

Mod para Minecraft Java 1.21.1 com NeoForge.

## O que já funciona
- Barra de mana roxa no canto inferior esquerdo
- Nível, EXP (matar monstros dá EXP) e 7 atributos
- Tecla **Z**: corte Demon-Slayer (gasta 20 de mana, recarga de 4 s)
- Comandos: `/bc status` e `/bc ponto <atributo>`

## Como gerar o .jar (sem instalar Java)
1. Crie uma conta grátis em github.com
2. Crie um repositório novo (botão "New") e envie TODOS os arquivos desta pasta
   (inclusive a pasta oculta `.github`). Dica: no site, "Add file > Upload files".
3. Abra a aba **Actions**. A compilação começa sozinha (leva uns 3 a 5 minutos).
4. Quando ficar verde, clique na execução e baixe **blackclover-mod** no fim da página.
   Dentro do zip está o arquivo `blackclover-0.1.0.jar`.

## Como instalar
1. Instale o **NeoForge 1.21.1** (neoforged.net) e abra o jogo uma vez.
2. Coloque o `.jar` na pasta `mods` (Windows: Win+R, digite `%appdata%\.minecraft\mods`).
3. Abra o Minecraft pelo perfil do NeoForge.

## Se der erro na compilação
Abra a execução com o X vermelho, copie a mensagem de erro e mande para o Claude.
